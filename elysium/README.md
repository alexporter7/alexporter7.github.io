# ELYSIUM — Cyberpunk Minecraft Realm Website

A stunning, immersive cyberpunk website for the **Elysium** Minecraft Realm.

## Features

- **Heavy neon cyberpunk aesthetic** with cyan, magenta, lime, and hot pink accents
- **Animated glitch title** with layered RGB split effect
- **Fully interactive holographic map** (HTML Canvas) — click nodes to open district details
- **6 unique districts** with rich lore and stats (click any district card)
- **Working application modal** with fake submission flow
- **Scanline CRT overlay** + terminal styling
- **Keyboard controls**:
  - `ESC` → Close any modal
  - `?` → Jump to The Grid
  - `N` → Quick brightness flash (night vision effect)
- Built with Tailwind + custom CSS + vanilla JavaScript (no build step required)

## How to Use

1. Open `index.html` directly in any modern browser (Chrome/Firefox/Edge recommended)
2. Everything works offline
3. Replace placeholder lore and images with your actual Realm screenshots
